# Project Explanation

## Problem Statement
Modern engineering teams need a single platform to manage tasks, understand work priority, and track delivery status. This project solves that by combining a responsive front-end, RESTful back-end, database persistence, and AI-style recommendation logic.

## What This Demonstrates

- HTML, CSS, JavaScript, React
- Responsive web application design
- Python FastAPI back-end development
- SQLAlchemy database modeling
- RESTful API implementation
- Front-end and back-end integration
- Docker deployment
- GitHub Actions CI/CD
- Clean SDLC practices
- AI-first development thinking

## API Endpoints

| Method | Endpoint | Purpose |
|---|---|---|
| GET | /health | Service health check |
| POST | /tasks | Create a task |
| GET | /tasks | List all tasks |
| GET | /tasks/{id} | Get one task |
| PUT | /tasks/{id} | Update task |
| DELETE | /tasks/{id} | Delete task |
| GET | /dashboard | Dashboard metrics |

## AI Logic
The application calculates an AI-style priority score based on task complexity and business impact. The score generates a recommendation such as critical, medium-high, normal, or low priority.

I created a professional AI-first workflow platform using React, FastAPI, SQLAlchemy, REST APIs, and Docker. The application supports task management, dashboard analytics, API integration, and AI-style priority recommendations. It is designed with clean code, responsive UI, database persistence, containerization, and GitHub Actions CI/CD.
